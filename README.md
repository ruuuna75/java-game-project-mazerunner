# Java Maze Game

A Java-based maze game developed as a team project at the Technical University of Munich.

## Demo

🎥 [Watch the gameplay demo on Google Drive](https://drive.google.com/file/d/1cmpd-wd38vqsKQDWxlXMtWsSzJ7JkUn8/view?usp=sharing)

## Overview
This project was developed as part of a university software development course. The game is a 2D maze-based application created collaboratively by a team of four students using Java and libGDX.

## My Responsibilities
I was mainly responsible for:
- Menu implementation
- HUD development
- Sound and background music integration
- Settings-related features
- Custom key bindings and control configuration
- In-game developer console
- Character progression and skill tree features

## Technologies
- Java

- Git
- GitHub

# 日本語

## 概要

Technical University of Munichの授業で、4人のチームで開発したJava / libGDXベースの2D迷路ゲームです。

プレイヤーは敵や罠を避けながら鍵を取得し、迷路から脱出します。スキルツリー、カスタムキー設定、Developer Console、セーブ機能などの追加機能も実装しました。
